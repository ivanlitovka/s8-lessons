# Задания спринта 8

Заполните `realization.py` в каталоге задания и выполните:

```bash
python3 submit.py
```

Нужен Python 3.9+

Сервис вычисляет поддерживаемые выражения DataFrame на Spark с тестовыми данными Kafka/PostgreSQL. Произвольный Python, UDF, SQL-выражения и пользовательские файлы сервер не выполняет. Функции, имена выходных DataFrame и запуск query сохраняйте как в заготовке.
Сервис не проверяет доступность вашей Kafka/PostgreSQL или учётные данные.
